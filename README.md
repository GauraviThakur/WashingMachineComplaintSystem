
# Washing Machine Complaint Management System

An API-first complaint management application for a washing machine manufacturing environment.

## Technology Stack

- Python 3.12
- FastAPI
- PostgreSQL
- SQL with a repository layer
- HTML, CSS and JavaScript
- Postman
- Git and GitHub

## Main Workflow

1. Individual complaint intake or bulk Excel/CSV upload
2. Manufacturing data verification
3. Duplicate detection and repeat complaint linking
4. Complaint registration
5. Inspection and supporting evidence
6. Priority evaluation and team assignment
7. Repair and rework attempts
8. Testing and quality verification
9. Final acceptance or rejection
10. Dispatch or approved final disposition
11. Complaint closure
12. Dashboard, notifications and PDF reporting

## Development Status

Initial project structure and API foundation.

## Local Setup

1. Create and activate a Python virtual environment.
2. Install dependencies using `python -m pip install -r requirements.txt`.
3. Configure environment variables in `.env`.
4. Start the API using `python -m uvicorn app.main:app --reload`.
5. Test the API using Postman.
